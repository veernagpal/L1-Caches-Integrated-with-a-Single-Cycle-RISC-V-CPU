# L1-Caches-Integrated-with-a-Single-Cycle-RISC-V-CPU
Implemented and verified three L1 data cache architectures for a single-cycle RISC-V CPU: Direct-Mapped, Fully Associative, and 2-Way Set-Associative. The Cache features ; write-back, write-allocate, LRU replacement, dirty block eviction, and 128-bit block transfers.
